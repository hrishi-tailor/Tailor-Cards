# Tableau dashboard

The dashboard shows how the business is doing on one screen:
- what each month earned
- what sells best, and where
- what unsold stock is worth today
- which held cards are moving in price

It reads the CSV files that the nightly warehouse run publishes. No live database connection is needed.

## Real data or demo data

| Use | Data | Tableau |
| :--- | :--- | :--- |
| Running the business | `s3://<data-lake bucket>/dashboard/*.csv`, refreshed nightly from the production ledger | **Tableau Desktop or Tableau Cloud only.** These keep the workbook private |
| Portfolio, interviews, a public link | `pipeline/demo-output/*.csv`, a synthetic year from `warehouse/demo.py` | Tableau Public is fine |

**Never put the real CSVs in Tableau Public.** Tableau Public publishes every workbook *and its data* for anyone to download. The demo data has the same columns, so one workbook works with either set: swap the data source with *Data > Replace Data Source*.

Download the real files:
```bash
aws s3 sync s3://$(terraform -chdir=infra/envs/staging output -json price_pipeline | jq -r .bucket)/dashboard/ ~/TailorCardsDashboard/
```

Generate the demo files instead:
```bash
cd pipeline && uv run --group dev python -m warehouse.demo demo-output
```

## Data sources

Add each CSV as a text-file connection. Set the types once; Tableau remembers them.

| File | One row per | Key fields |
| :--- | :--- | :--- |
| `dash_sales.csv` | Sale | `sold_on`, `month_start`, `week_start` (dates); `item`, `kind_name`, `card_name`, `channel_name`, `channel_type`; `units`, `revenue_cad`, `cost_cad`, `gross_profit_cad`, `days_listed`; `is_giveaway` (boolean) |
| `dash_prices.csv` | Card per day | `price_date` (date); `card_name`, `in_ledger`; `price_cad` |
| `mart_inventory_valuation.csv` | Lot with stock left | `title`, `kind_name`; `units_on_hand`, `cost_on_hand_cad`, `market_value_cad`, `unrealised_gain_cad`, `price_age_days` |
| `mart_price_movers.csv` | Card held or listed | `card_name`, `price_cad`, `change_pct` |
| `dq_results.csv` | Data-quality check | `check_name`, `severity`, `failing_rows` |

The monthly and weekly marts are pre-aggregated copies of `dash_sales`. They are handy for checking totals; the sheets below aggregate `dash_sales` directly.

## Calculated fields (on `dash_sales`)

| Name | Formula |
| :--- | :--- |
| Margin % | `SUM([gross_profit_cad]) / SUM([revenue_cad])` (format as a percentage) |
| Avg sale | `SUM([revenue_cad]) / COUNTD([sale_id])` |
| Median days listed | `MEDIAN([days_listed])` |
| Profit per unit | `SUM([gross_profit_cad]) / SUM([units])` |

## Sheets

| Sheet | Build | Answers |
| :--- | :--- | :--- |
| **KPIs** | Four text tiles: Revenue, Gross profit, Margin %, Units, for the selected period. `sold_on` filter set to *Relative dates* (default: last 3 months) | How are we doing? |
| **Monthly P&L** | Columns `MONTH(month_start)`; bars `SUM(revenue_cad)`; dual-axis line Margin % | Is profit growing, and is margin holding? |
| **Kind × channel** | Rows `kind_name`; columns `channel_name`; colour Margin %; label `SUM(gross_profit_cad)` | What sells best where? |
| **Time to sell** | Box plot of `days_listed` by `kind_name` | Which stock ties up money longest? |
| **Stock at market** | From `mart_inventory_valuation`: bars of `market_value_cad` and `cost_on_hand_cad` per `title`, sorted by `unrealised_gain_cad`; colour by gain sign | What's unsold stock worth, and what should I list? |
| **Price movers** | From `dash_prices`, filtered to `in_ledger`: line of `price_cad` over `price_date` per `card_name`, last 90 days; the `mart_price_movers` table beside it | Which held cards should I sell or hold? |
| **Data health** | From `dq_results`: `check_name` coloured by `failing_rows > 0` | Can I trust these numbers today? |

## Dashboard layout (1200 × 800)

```text
┌──────────────────────── KPIs (4 tiles) ─────────────────────────┐
├──────────── Monthly P&L ────────────┬──── Kind × channel ───────┤
├──────────── Stock at market ────────┼──── Price movers ─────────┤
└──────────── Time to sell ───────────┴──── Data health (small) ──┘
```

- Apply the `sold_on` and `channel_type` filters to every `dash_sales` sheet.
- Clicking a cell in *Kind × channel* filters *Monthly P&L*: add a dashboard action of type *Filter*, from Kind × channel to Monthly P&L.
- Title it "Tailor Cards: trading dashboard". For the demo version, add a caption: "Synthetic data generated by the warehouse demo; no real sales."

## Refreshing

The nightly run replaces the CSVs at 4 AM. Rerun the `aws s3 sync` command, then choose *Data > Refresh All Extracts* in Tableau. Tableau Cloud can instead read the files through a scheduled flow or a Google Drive or OneDrive sync folder.
